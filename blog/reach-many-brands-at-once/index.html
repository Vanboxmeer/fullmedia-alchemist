Run outreach for every brand at once: tick, start, done

Reach keeps each brand separate but lets Claude work on as many as you tick in a single run. Here is how one afternoon covers your whole client list.

The Alchemist
November 11, 2026 · 5 min read

Most outreach tools make you switch accounts, one brand at a time. Reach holds every brand in one workspace, so the first step of a run is simply ticking the brands you want worked on today.

How a multi-brand run works

  1. In each brand, build the list and write the messages. Accept the ones you like and mark them Ready to send.
  2. Open Automation and tick the brands Claude should work on. Brands you leave unticked are never touched.
  3. Press Save selection, switch Automation on, and send one line in Claude: Check my Alchemist Reach tasks.

Claude then takes the approved messages one at a time, across every ticked brand, with a pause between sends. Each message goes out as that brand's own sender, with that brand's signature, from that brand's mail account.

What stays separate

Every brand keeps its own prospects, drafts, tone, signature and sending address. Reach checks the mail account before it sends for a brand, and a brand whose account is not confirmed sends nothing. Details are in account managers per brand.

One limit across the run

The daily limit (up to 40, default 15) and the gap between sends apply to the run as a whole, not to each brand. If you want one brand to get more of the day, tick only that brand for the first run.

You stay in control

Nothing is sent that you did not approve. The window shows how many messages are selected, how many are new emails, web forms and follow-ups, and how many went out today. Anything that needs you, like a login or a payment, is flagged and skipped. Read more in Reach automation with Claude.

The same idea in Content

If you also run Content, the brands you set up there are the same brands under the same login. One person can approve a brand's posts, and the auto-post feature in Content can publish them while Reach handles the outreach for the same client. Take both on matching plans and you pay 10% less than buying them separately.
